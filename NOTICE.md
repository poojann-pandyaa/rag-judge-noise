# Data and third-party material

## Included in this repository

| File | Source | Licence / terms |
|---|---|---|
| `data/eval_set.jsonl`, `data/answers.jsonl` | A 250-question sample of the CLAPnq development set (Rosenthal, Sil, Florian, Roukos. TACL 13:53-72, 2025, https://aclanthology.org/2025.tacl-1.3), repository https://github.com/primeqa/clapnq (commit pinned in `data/manifest.json`). `answers.jsonl` also holds answers generated by Mistral-7B-Instruct-v0.3 and the retrieved passages. | Dataset released under Apache-2.0 (dataset card: https://huggingface.co/datasets/PrimeQA/clapnq). The passages originate from Wikipedia and Natural Questions; check those terms (CC BY-SA for Wikipedia text) if you redistribute further. |
| `data/ragtruth_eval.jsonl` | Response ids, sentence indices and human hallucination labels derived from RAGTruth (Niu et al., ACL 2024, https://aclanthology.org/2024.acl-long.585), repository https://github.com/ParticleMedia/RAGTruth. **Only ids and labels are included; the source passages and response text are not.** | RAGTruth repository is MIT-licensed. Run `python3 ragtruth.py prepare` after downloading the data to rebuild the full file. |
| `data/judgments/*.jsonl`, `data/results/*`, `figures/*`, `article_figures/*` | Produced by this project's code. They contain numbers and ids only. | MIT (same as the code) |

## Not included

* Model weights: Qwen2.5 (0.5B, 1.5B, 3B, 7B), Llama-3.2 (1B, 3B), Llama-3.1 (8B), Mistral-7B-Instruct-v0.3, and `BAAI/bge-base-en-v1.5` are downloaded from Hugging Face at the revisions pinned in the scripts.
  They keep their own licences (for example Mistral 7B is Apache-2.0, bge-base-en-v1.5 is MIT, Llama models use Meta's community licence, and Qwen2.5-3B uses Qwen's research licence). Check each model card before commercial use.
* The retrieval index (about 470 MB) and the raw dataset downloads: regenerate with `setup_clapnq.py` and `rag.py index`.
